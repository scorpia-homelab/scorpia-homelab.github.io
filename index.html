How publishing works

01 · MEASURE

Genuine runs only. Fixed prompts, budgets and checks in one registry; every test writes its own atomic result files. Nothing on this site is hand-typed.

02 · SCRUB

Private stays private. A scrubber replaces internal hosts with public hardware labels, then a leak gate fails the build if any internal IP, hostname or port survives.

03 · PUBLISH

Automated end to end. CI rebuilds every page from the raw data and ships it to GitHub Pages — the numbers you see were built by the pipeline, not edited by hand.
