The link

The Mandelbrot set is the table of contents of the Julia family. For every complex number c, the map z ← z² + c carves a Julia set Jc out of the plane — the boundary of the points that stay bounded. The Mandelbrot set is exactly the set of c for which Jc is connected. So the left panel is a map of the right one: click it, and the amber ring marks your c while the Julia set redraws itself. Inside the black set, Julia sets are whole; a hair's breadth outside, they dissolve into dust.
