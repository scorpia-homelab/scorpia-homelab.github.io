The Mandelbrot set is a table of contents. Each Julia set is one of the chapters it indexes.

Escape time
Iterate z ↦ z² + c. The moment |z| > 2 the orbit is provably unbounded — from there every iterate grows without limit. Points that never cross the radius within the iteration budget are drawn as the filled interior.
Fractional counts
Whole-number counts produce hard bands. The continuous estimate n + 1 − log₂(log|z|) asks where inside the escape ring the orbit slipped out, and the banding dissolves into smooth gradients.
Plate I — parameter plane
Here the pixel is the constant c, and the orbit always begins at the critical point z = 0. The set of c whose orbit stays bounded is M: a catalogue with exactly one entry per connected quadratic Julia set.
Plate II — dynamical plane
Here c is fixed and the pixels are starting points. The boundary between the points that flee and the points that stay is the Julia set J_c — a curve with zero area that no amount of zoom ever flattens.
The bridge
Douady–Hubbard: c ∈ M ⟺ J_c is connected. Move c outside Plate I and Plate II shatters into a Cantor dust. That is why the crosshair on Plate I is the most honest control on this page.
Critical orbit
The glowing path on Plate II is 0 ↦ c ↦ c²+c ↦ …. The map has exactly one finite critical point, and its fate decides everything: it must fall into an attractor, or the Julia set is disconnected.
Precision floor
Below a vertical span of roughly 10⁻¹², IEEE-754 doubles stop resolving neighbouring pixels and the image pixelates. That is the machine running out, not the set running out.

Controls

Plate I: scroll to zoom toward the cursor, drag to pan, double-click to go home. A click pins c; click again to move the pin.

How it is drawn

Each plate is computed on the CPU in scanline chunks against a 12 ms frame budget, in three progressive passes (¼, ½, full resolution) so the image is never blank. The cardioid and period-2 bulb are rejected analytically before iterating.

Escape values are cached in a Float32Array, so palette, drift and band-density changes recolour the plate from the LUT without re-iterating a single point — which is what makes the palette drift cheap enough to leave running.

Colour is a 1024-entry cyclic lookup table indexed by √n, with a per-pixel dither to break up quantisation steps.
