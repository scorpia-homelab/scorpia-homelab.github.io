Plate II · Notes

How the plate is drawn

Both pictures answer the same question — does this point escape? — of two different variables. That shared question is what makes them speak to each other.

Start anywhere and iterate zn+1 = zn² + c. Squaring doubles every angle and squares every modulus, so magnitudes above one run away geometrically; anything that survives a few hundred rounds is very likely trapped forever. The escape-time method simply colours a point by how long it took to blow past a bailout radius of |z| = 256.

μ = n + 1 − log₂ ( log|zn| ⁄ log 256 ) continuous potential — removes the contour banding

On the left, z is pinned at zero and c walks the plane: each pixel is an entirely different dynamical system, and the black region is the catalogue of rules whose orbit of zero never escapes. On the right, c is pinned and z walks the plane: the black region is the filled Julia set Kc, and its boundary is the Julia set proper — the locus of initial conditions whose fate is undecided, however finely you look.

Rendering notes

Each frame is computed in three progressive passes at 1⁄4, 1⁄2 and full resolution, row-chunked inside a 14 ms budget so the interface never stalls. Interior points are rejected instantly by the cardioid and period-2 bulb tests, then by cycle detection (a repeated iterate means a trapped orbit). Colour comes from a 1024-entry cyclic lookup table indexed by μ0.32, so the ramp repeats smoothly as depth grows. Zoom depth automatically buys extra iterations — about 110 per decade.
