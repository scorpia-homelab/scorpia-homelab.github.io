The map

Everything on this page is z ↦ z² + c — the simplest non-linear map in the complex plane. Orbits that stay bounded draw the sets; orbits that escape draw the color.

Mandelbrot

Each pixel is a candidate c. Start at z₀ = 0 and iterate z ← z² + c. If |z| ever exceeds 2 the orbit diverges to ∞; if it never does, the pixel belongs to the set.

Julia

Now c is fixed and each pixel is a starting point z₀. Every c has its own Julia set — and the Mandelbrot set is the map of exactly those c whose Julia set is connected.

Coloring

Escape time, smoothed: n + 1 − log₂ log₂|z|, sampled from a cyclic palette that can drift slowly through its own spectrum.

Engine

No libraries, no WebGL — plain JavaScript arithmetic over a canvas ImageData buffer. Roughly 400,000 pixels per panel, recomputed live as you pan, zoom, or move c.
