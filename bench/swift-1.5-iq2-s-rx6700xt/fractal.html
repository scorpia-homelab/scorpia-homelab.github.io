Mandelbrot and Julia Sets

Both images use escape-time coloring for the quadratic map zn+1 = zn² + c. Drag to pan, scroll to zoom. The Julia parameter c is adjustable.

Mandelbrot Set

Scroll to zoom, drag to pan.
Mandelbrot: start at z₀ = 0; each pixel is a value of c.

Julia Set

Julia: fixed c; each pixel is the starting value z₀.
